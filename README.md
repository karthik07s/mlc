# MLC

MLC is a blue-branded, modified version of [VLC for Android](https://code.videolan.org/videolan/vlc-android)
(GPLv2 / LGPL). This repository contains only the changes (`mlc-rebrand.patch`) and a GitHub Actions
workflow that builds the APK from the official source. Original VLC source: commit `8281580`.

MLC is not affiliated with or endorsed by VideoLAN. "VLC" and the cone logo are VideoLAN trademarks.

To build: Actions tab -> "Build MLC APK" -> Run workflow. The APK appears under "Artifacts" when done.
